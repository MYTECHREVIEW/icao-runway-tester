📚 API & Touchdown Integration Docs
Complete guide for consuming the REST API, receiving touchdown telemetry arrays, and pushing landing coordinates into the map.
🔑 Authentication

All /api/v1/* endpoints require your API key in the request header:

X-API-Key: rwy_your_generated_key
📡 REST API Endpoints
Method Endpoint Description
POST/api/v1/touchdownAnalyze landing touchdown point — returns centerline deviation, TDZ, remaining dist, rating & static map images
GET/api/v1/map/static?lat=&lon=Generate high-res Mapbox static image with touchdown dot — supports satellite, dark, runway rotation & 3D pitch
GET/api/v1/airport/:icaoAirport info — name, IATA, lat/lon, elevation, timezone
GET/api/v1/airport/:icao/runwaysAll calibrated runways — coordinates, headings, length, surface
GET/api/v1/airports/search?q=Instant search across 85,917 airports by ICAO, IATA, name, or city
GET/api/v1/airport/:icao/weatherLive METAR + ATIS (Real-world D-ATIS, VATSIM, IVAO)
GET/api/v1/airport/:icao/notamsActive NOTAMs and closed runway designator alerts
🎯 Push Touchdown GPS Coordinates into the Map (No Manual Pin Drop)

There are 3 ways to automatically drop the landing pin and display touchdown metrics in the web interface:

Option A: Deep Linking via URL Query Parameters

Open or embed the map with coordinates in the URL:

https://your-server.com/?touchdown=40.77665,-73.87185
https://your-server.com/?lat=40.77665&lon=-73.87185&icao=KLGA&fpm=-135&ias=132&g=1.14
Option B: Real-Time postMessage (For Iframes & Desktop Sim Connectors)

Push live telemetry dynamically from your parent app or Electron bridge:

// From your Electron / React / Sim client:
const iframe = document.getElementById('runwayMapIframe');
iframe.contentWindow.postMessage({
  type: 'TOUCHDOWN',
  lat: 40.77665, lon: -73.87185, icao: 'KLGA',
  vertical_speed_fpm: -135, ias_kt: 132, g_force: 1.14, heading: 212
}, '*');
Option C: Top Bar "🎯 Touchdown GPS" Button

Click the button in the map header or paste 40.77665, -73.87185 directly into the search bar.

🛬 POST /api/v1/touchdown — Request & Response Schema

Request Body (JSON)

{
  "lat": 40.77665,               // Required: GPS decimal latitude
  "lon": -73.87185,              // Required: GPS decimal longitude
  "heading": 212,                // Optional: Aircraft heading (deg)
  "vertical_speed_fpm": -135,    // Optional: Touchdown sink rate (ft/min)
  "ias_kt": 132,                 // Optional: Touchdown airspeed (knots)
  "g_force": 1.14,               // Optional: Impact G-load
  "icao": "KLGA"                 // Optional: Airport override
}

💻 Code Examples (JavaScript / TypeScript & Python)

JavaScript / TypeScript (Fetch & Array Parsing)

const API_URL = 'https://your-server.com';
const API_KEY = 'rwy_your_key_here';

async function submitTouchdown(lat, lon, fpm, ias) {
  const res = await fetch(`${API_URL}/api/v1/touchdown`, {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'X-API-Key': API_KEY
    },
    body: JSON.stringify({ lat, lon, vertical_speed_fpm: fpm, ias_kt: ias })
  });

  const data = await res.json();
  if (data.touchdown) {
    console.log(`🛬 Landed on Runway ${data.touchdown.runway_ident}`);
    console.log(`📐 Centerline: ${data.touchdown.centerline_deviation.text}`);
    console.log(`📏 Threshold: ${data.touchdown.threshold_distance.distance_from_threshold_ft} ft`);
    console.log(`⭐ Rating: ${data.touchdown.flight_telemetry.landing_rating}`);
  }

  // Iterate all runways array:
  data.all_runways.forEach(r => {
    console.log(`Runway ${r.runway}: ${r.length_ft}ft (${r.surface}) - Deviation: ${r.deviation_ft}ft`);
  });
}

Python (requests)

import requests

resp = requests.post(
    "https://your-server.com/api/v1/touchdown",
    headers={"X-API-Key": "rwy_your_key_here", "Content-Type": "application/json"},
    json={"lat": 40.77665, "lon": -73.87185, "vertical_speed_fpm": -135, "ias_kt": 132}
)
data = resp.json()

if "touchdown" in data and data["touchdown"]:
    td = data["touchdown"]
    print(f"Runway: {td['runway_ident']} | Deviation: {td['centerline_deviation']['text']}")
    print(f"Threshold: {td['threshold_distance']['distance_from_threshold_ft']} ft | Rating: {td['flight_telemetry']['landing_rating']}")
